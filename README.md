# Nogbase

Nogbase is a modular platform for building CRM, workflow, and internal operations tools on top of a PocketBase-style backend.

It brings together a backend foundation, developer tooling, and frontend apps so teams can move quickly from MVP to production-ready workflows.

## What Nogbase focuses on

- Custom CRM and operational workflows
- Fast internal tool development
- Auth, data modeling, and admin foundations
- Frontend apps for operators, brokers, and customer-facing teams
- A practical path from prototype to SaaS

## Repositories

- `nogbase-app` - Full application workspace with frontend and backend services
- `nogbase-mvp` - Early MVP workspace for rapid product validation
- `nogbase-saas` - SaaS-oriented implementation and experiments
- `.github` - Shared community health files, templates, and GitHub automation

## Core stack

Nogbase is built around a modern web stack that includes:

- PocketBase-style backend foundations
- TypeScript
- React and Vite
- pnpm workspaces
- Go for backend services and extensions

## Philosophy

Nogbase is designed for teams that want:

- Simple infrastructure
- Fast iteration
- Strong control over data and workflows
- A codebase they can extend without fighting the framework

## Getting started

Start with the repository that matches your current stage:

- Use the MVP repo if you are validating product direction
- Use the app repo if you are building the main product
- Use the SaaS repo if you are working on multi-tenant or packaged deployment flows

Each repo contains its own setup instructions and local development commands.
